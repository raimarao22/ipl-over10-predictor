# Beat the Commentator: IPL Score Prediction at Over 10

ES 335 (Machine Learning) project by Raima Rao and Rishit Garg.

At the end of over 10 of an IPL first innings, can machine learning predict the final total
better than the commentator's rule of thumb (score x 2)?

Website: https://raimarao22.github.io/ipl-over10-predictor/

## Reproduce

1. `pip install -r requirements.txt`
2. Put the Cricsheet zip in `data/` (see `data/README.md`; check the SHA-256).
3. From the repo root, run in this order:

| # | Script | What it does | Output |
|---|---|---|---|
| 1 | `src/build_snapshots.py` | One row per first innings at end of over 10; applies exclusions | `data/first_innings_over10.csv`, `results/exclusions.json` |
| 2 | `src/check_snapshots.py` | Independent over-by-over recount of 10 innings | Prints "All checks passed." |
| 3 | `src/baselines.py` | x2 rule, learned ratio, median on walk-forward folds 2019-2024 | `results/baseline_results.csv` |
| 4 | `src/features.py` | Venue average, league scoring level, Impact Player era (earlier matches only) | `data/features_over10.csv` |
| 5 | `src/check_features.py` | Recomputes historical features by hand to confirm no leakage | Prints "All feature checks passed." |
| 6 | `src/train_validate.py` | Model and feature selection on walk-forward folds; frozen weights | `results/validation_results.csv`, `results/oos_predictions.csv`, `results/chosen_model.json` |

Files in `data/` are regenerated by the scripts and not committed.
Files in `results/` are committed so the repo records the claimed results.

## Split

- Development: 2008-2024. Walk-forward folds: each season 2019-2024 is predicted using only earlier seasons.
- Final test: 2025-2026, evaluated once after the model is frozen (not yet run).
- Historical features always use matches from strictly earlier dates only.

## Current selected model (validation only, 2025-2026 not used)

Selected by the rules in `src/train_validate.py`; full results in `results/`.

- **Model:** ridge regression, alpha = 100, trained on 2008-2024
- **Features:** runs at over 10, wickets at over 10, Impact Player era (seasons from 2023)
- **Formula:** runs still to come = 94.47 + 0.109 x runs_10 - 5.725 x wkts_10 + 8.765 x impact_era;
  predicted total = runs_10 + runs still to come
- **Dropped:** overs 6-10 and 9-10 momentum, venue average, rolling league scoring level
  (each changed walk-forward MAE by less than 0.1 runs)

| Method (walk-forward folds 2019-2024) | MAE (runs) |
|---|---|
| Commentator rule (runs_10 x 2) | 22.0 |
| Learned ratio (runs_10 x k) | 20.3 |
| **Selected ridge model** | **16.8** |

- vs x2 rule: 5.2 runs lower MAE (paired bootstrap 95% CI 3.8 to 6.6)
- vs learned ratio: 3.5 runs lower MAE (95% CI 2.1 to 4.9)
- vs ridge on runs_10 alone: 0.4 runs lower, not statistically established (95% CI -0.3 to 1.1)
- 90% prediction interval: prediction - 30.2 to prediction + 38.7 runs;
  empirical coverage on folds 2020-2024: 87%
- Mean signed error on 2023-2024: -7.1 runs (still underpredicts the Impact Player era)

Because choices were made on the same folds, these validation numbers are slightly optimistic;
the 2025-2026 test gives the unbiased estimate.
